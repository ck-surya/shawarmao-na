# Page & Component Specification

## Homepage
Sticky header, restaurant identity, open/closed status, hero food image, Order Now CTA, popular items, category navigation, menu, direct-order explanation, location, hours and footer/legal links.

## Menu item card
Food image, name, short description, price, verified dietary marker and add button. Add changes into a quantity stepper. Keep decoration minimal.

## Category navigation
Horizontal scroll on mobile. Active category clearly indicated without neon/glow.

## Cart
Mobile bottom sheet; desktop drawer/side panel. Items, quantity, remove, subtotal, fees, total and checkout.

## Checkout
Short form. Delivery/pickup first. Name, phone, address/notes as needed. Clear validation.

## Confirmation
Success state, order number, summary, current status and tracking/support path.

## Tracking
Timeline: Order received → Confirmed → Preparing → Ready → Out for delivery → Delivered. Subtle active motion.

## Admin
Scannable order board with New, Confirmed, Preparing, Ready and Out for delivery. Restrained status colors and strong typography.

## Responsive QA
Test 320px, 375px, 390px, 430px, 768px, 1024px and 1440px.

## Accessibility
Keyboard access where applicable, visible focus states, sufficient contrast, form labels, adequate touch targets and reduced-motion support.
