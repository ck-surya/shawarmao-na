# Content & Data Rules

## Source of truth
Restaurant menu, pricing, hours, address, phone, availability and customizations must be confirmed with the owner before production. Public listings can become outdated.

## Never invent
Do not invent menu items, ingredients, prices, discounts, delivery fees, preparation times, reviews, testimonials, restaurant claims, payment success or delivery integrations.

## Menu item fields
Name, description, price, category, image, availability, verified dietary marker and verified customization/options.

## Customer data
Collect only what is needed: name, phone, delivery address for delivery, order notes where needed.

## Totals
Client submits item IDs/quantities. Server fetches current prices and calculates subtotal, discount, delivery fee and total.

## Reviews
Only use real reviews with appropriate attribution. Never fabricate quotes.

## Promotions
Only show explicitly configured promotions. Do not create fake urgency or fake discounts.
