# Menu dish illustrations

Generated with the built-in image_gen tool. These are representative gouache illustrations, not photographs of restaurant servings. The cards label them `Dish illustration`; ingredients, portion size and plating are not promises. Staff-supplied image paths always take priority, and illustration fallbacks only match unchanged source item names and IDs.

Assets are optimized WebP files under `public/images/dishes/`, 960 × 720. They are served locally through Next.js Image with responsive sizes, eager loading for the first menu row, and lazy loading below it. Original generated PNGs remain at their tool-provided locations.
